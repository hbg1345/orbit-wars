# 알파스타 논문 소개

이거보다 훨씬 복잡한 스타크래프트의 ai에 대해 연구한 alpha star라는 논문을 이해했다.

!image.png

모델의 구조가 위와 같은데, 주목할 만한 점은 유닛과 타겟 유닛을 선택하는 과정이다.

선택해야 하는 유닛의 수가 게임 상황에 따라 계속 달라지기 때문에, 가변 길이에 대응할 수 있는 모델이 필요하다. 이를 만족하는 것이 어텐션을 약간 수정한 pointer network라는 것이다.

선택된 유닛을 임베딩 후, 어텐션을 통해 타겟 유닛을 뽑아낸다. 이 후 포인트를 클릭하여 공격하는 방식이다. 

Orbit Wars와 스타크래프트는 많이 비슷한 구석이 있다. 

유닛을 선택하는 부분이 우리 게임에 적용될 만하다.

우리 게임은 유닛의 수가 정해져 있기 때문에, pointer network는 생략하도록 하고, target unit만 잘 골라주면 된다.

attention메커니즘을 사용해서, 보낼 함대의 수를 직접적으로 예측하게 하면 좋을 것이라고 생각한다.

# **유닛의 피쳐**

1. 종류
2. 시간 별 함대 수
3. 시간 별 소유자
4. 반지름
5. 시간 별 위치
6. 남은 생명

# 보상 함수

500턴으로 끝났을 때, 보유하고 있는 함대 수를 보상으로 설정한다.

# 네트워크 구조

1. 40개의 행성 + 혜성의 피쳐를 구성한 뒤, 임베딩 레이어를 통과시킨다.
2. 마스크드 어텐션을 통해 내 소유의 행성과 다른 모든 행성들과의 어텐션을 수행한다.
3. mlp를 수행하는데, 보낼 함대의 개수를 여기서 예측한다.
4. 예측한 함대의 개수를 보낼 수 있도록 후처리를 한다.

# 학습 방식

알파스타의 경우, 처음에 지도 학습을 하고, 상위 20% 유저로 파인 튜닝을 했다고 한다.

캐글에서 유저들의 대전 기록을 제공하기 때문에, 마찬 가지의 방식을 적용하려고 한다.

데이터의 크기에 따라 상위 유저의 비율을 조절해볼 생각이다.
